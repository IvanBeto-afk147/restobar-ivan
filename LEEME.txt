# RestoBar Ivan - Sitio web multipágina

## Archivos principales
- `index.html`: Inicio
- `menu.html`: Menú de comidas, bebidas y postres
- `nosotros.html`: Información del restaurante
- `galeria.html`: Galería de imágenes
- `pedidos.html`: Formulario para realizar pedidos
- `administracion.html`: Panel de administración
- `style.css`: Diseño y estilos compartidos
- `script.js`: Navegación y funcionalidades
- `menu.json`: Productos
- `images/`: Imágenes locales

## Cómo probar
1. Extrae toda la carpeta del ZIP.
2. Abre la carpeta en Visual Studio Code.
3. Ejecuta `index.html` con Live Server.
4. Usa la barra superior para navegar entre las páginas.

## Importante sobre los pedidos
Los pedidos se guardan en `localStorage` del navegador. Por eso, el panel de administración solo muestra los pedidos guardados en ese mismo navegador y dispositivo. Esta práctica no utiliza una base de datos ni un sistema de administración protegido para varios usuarios.
